## A4 Mock mode / keys
- Record-once/replay-many fixtures are the common LLM test pattern: record with a real key, commit JSON fixtures, replay with no network/key; opt-in recording via env var; credentials redacted from fixtures; main trade-off is request matching (exact breaks on prompt change; fuzzy hides drift; re-record on prompt change). Seen in Sycophant (Elixir), llm-mock (Python), llm-vcr (PHP), CopilotKit aimock, Speedscale proxymock. All small/young tools; survey via search snippets only. | https://hexdocs.pm/sycophant/0.4.2/recording-tests.html ; https://pypi.org/project/llm-mock/ | various | undated | 2026-10-28 | low-medium | pattern
- Config/secrets belong in environment variables, strictly separated from code (twelve-factor), supporting an env flag + .env approach. | https://12factor.net/config | 12factor.net | undated | 2026-10-28 | high | practice
- GitHub secret scanning runs automatically and free on public repos; if a key leaks, rotate/revoke immediately; history rewrite often unnecessary once revoked. (Push protection not covered by that page.) | https://docs.github.com/en/code-security/secret-scanning/introduction/about-secret-scanning | GitHub | undated | 2026-10-28 | high | practice
