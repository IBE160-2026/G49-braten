## Cost arithmetic (assumptions: 18k input tokens, ~5k output tokens for summary+flashcards+quiz+key terms+JSON overhead; one call; prices above; Claude tokens may be ~30% higher than other tokenizers, i.e. ~23k input — still <100k tier)
- Claude Haiku 5.5: 18,000*$0.10/1M = $0.0018; 5,000*$0.50/1M = $0.0025; total ~$0.0043 (~$0.0050 with 23k tokens). 1000 PDFs ~ $4-5.
- Claude Sonnet 5.5: 18k*$2/1M = $0.036; 5k*$10/1M = $0.05; total ~$0.086.
- Gemini 2.5 Flash-Lite: 0.0018 + 0.0020 = ~$0.0038 (free tier available; paid only if limits exceeded).
- Gemini 3.1 Flash-Lite: 0.0045 + 0.0075 = ~$0.012.
- Gemini 2.5 Flash: 0.0054 + 0.0125 = ~$0.018.
- OpenAI gpt-5-nano: 0.0009 + 0.0020 = ~$0.0029; gpt-5-mini: 0.0045 + 0.010 = ~$0.0145.
- Groq gpt-oss-20b: 0.00135 + 0.0015 = ~$0.0029; gpt-oss-120b: 0.0027 + 0.003 = ~$0.0057.
- Caveat: reasoning/thinking tokens on thinking models are billed as output and could multiply output cost several-fold (not quantified by a source here).
- Conclusion: every cheap-tier paid option costs under ~2 cents per PDF; cost is not the discriminator, free-tier availability for the examiner is. Only Gemini (free tier confirmed Yes) and OpenRouter :free (limits confirmed) have evidenced no-card free access; Groq/Mistral free API unconfirmed.
